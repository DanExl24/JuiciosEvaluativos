# Agent Rules and Guidelines

## Git Workflow: Atomic Commits & Push
- **Atomic Commits**: Cada vez que se complete un cambio, mejora, corrección o funcionalidad, realiza un commit atómico con un mensaje claro y descriptivo siguiendo Conventional Commits (e.g., `fix(parser): ...`, `feat(projects): ...`, `refactor: ...`).
- **Push Inmediato**: Tras realizar el commit, ejecuta `git push` para mantener sincronizado el repositorio remoto de inmediato.
